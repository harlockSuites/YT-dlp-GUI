Графический интерфейс для [yt-dlp](https://github.com/yt-dlp/yt-dlp), созданный, чтобы сделать его доступным каждому и полностью использовать его возможности.

> **Проект в разработке.** Некоторые функции могут меняться, быть неполными или содержать ошибки.

## Возможности

### Одиночная загрузка и очередь

- **Параметры**: максимальное качество (вплоть до 4K), только звук (MP3), субтитры (форматы vtt, srt, ass), встраивание субтитров и миниатюры, основной язык звука, дополнительные аудиодорожки (многодорожечный файл MKV) и библиотека «блоков скриптов» (постобработка, экспорт, сеть, поведение), которую можно дополнить собственными блоками.
- **Сформированная команда**: команда yt-dlp, соответствующая вашему выбору, отображается в реальном времени.
- **Очередь**: добавьте текущий URL, затем запустите всю очередь, начиная с выбранного элемента, одно видео или диапазон; пауза и возобновление, пропуск текущего элемента, остановка с удалением частичных файлов. Очередь сохраняется между сеансами.

### Инспектор плейлистов

- **Анализ** плейлиста: каждое видео показывается вместе с доступными аудиодорожками и субтитрами; скрытые, приватные и удалённые элементы пропускаются, не мешая остальным.
- **Общие правила** (качество, только звук, формат и встраивание субтитров, миниатюра, нумерация, языки, блоки скриптов, папка вывода) с **исключениями для отдельных видео** по основному языку, дополнительным дорожкам и субтитрам.
- **Цветовая маркировка**: красный — нет основного языка, оранжевый — нет дополнительной дорожки или субтитров.
- **Загрузка выбранного** с журналом, паузой, возобновлением и пропуском; если запрошенных дорожек нет, видео повторяется без них, а затем **итог** показывает, что удалось, что было скорректировано и что завершилось ошибкой.

### Умная папка и реестр

- **Умная папка**: yt-dlp пропускает уже загруженные видео благодаря реестру, хранящемуся в папке вывода. Файл `.yt-dlp-registre.json` содержит идентификатор, URL, название, длительность, имя файла и дату каждого видео; `.yt-dlp-archive.txt`, который читает yt-dlp, создаётся на его основе.
- **Ретроспективная проверка**: если видео из выбранного уже лежат в папке, но не числятся в реестре, окно предлагает внести их и пропустить (сравнение названий). Ложные совпадения можно снять.
- **Обновить реестр**: подсчитывает видео в папке, в реестре и недостающие, затем ищет недостающие сведения на YouTube (название и длительность через ffprobe). Ничто не вносится без вашего подтверждения, а две кнопки открывают локальный файл или найденную ссылку YouTube для проверки.

### Cookie браузера

- Выберите браузер (Chrome, Firefox, Edge, Brave, Opera), cookie которого yt-dlp читает локально: они нужны для дополнительных аудиодорожек и некоторых субтитров.
- **Индикатор** показывает состояние: красный — отключено или ошибка, оранжевый — не проверено или идёт проверка, зелёный — cookie загружены. Кнопка ↻ запускает проверку, а подсказка объясняет состояние или ошибку.

### Мастер установки, зависимости и обновления yt-dlp

- **Мастер установки**: при первом запуске предлагает скачать yt-dlp и ffmpeg из их официальных репозиториев GitHub. Контрольная сумма SHA-256 проверяется, права администратора не нужны.
- **Зависимости**: отдельное окно проверяет ffmpeg, ffprobe, AtomicParsley, MKVToolNix, aria2 и deno и может установить их через Chocolatey.
- **Обновление и диагностика**: обновляет yt-dlp (`yt-dlp -U`) или заменяет его исполняемый файл, показывает версию и проверяет параметры, используемые интерфейсом.
- **Обновление программы**: ежедневная проверка (её можно отключить) сообщает о новой версии неприметной полосой; отдельное окно показывает, что нового, и открывает загрузку, соответствующую вашей установке (установщик или портативная версия). Ничего не устанавливается автоматически.

### Интерфейс и языки

- Элементы управления перестраиваются по ширине окна; содержимое прокручивается по вертикали, а таблица инспектора — ещё и по горизонтали.
- Интерфейс на **15 языках**: французский, английский, испанский, португальский, итальянский, польский, венгерский, сербский, русский, вьетнамский, китайский, хинди, японский, корейский и филиппинский. Смена языка применяется после перезапуска, с возможностью перезапустить сразу.

### Сообщить об ошибке

- Кнопка «Сообщить об ошибке» готовит технический отчёт: версии программы, Python, Windows и yt-dlp, безопасные настройки и последние строки журнала. Ваши папки, имя пользователя и адреса электронной почты скрываются.
## Установка

- **Установщик (рекомендуется)**: скачайте `yt-dlp-gui-setup-X.Y.Z.exe` со [страницы выпусков](https://github.com/harlockSuites/YT-dlp-GUI/releases) и запустите его. Windows 10 или 11 (64 бита), права администратора не нужны; Python не требуется.
- **Портативная версия**: скачайте `yt-dlp-gui-portable-X.Y.Z.zip`, распакуйте куда угодно и запустите `yt-dlp-gui.exe`; настройки остаются в этой папке.
- **Из исходного кода**: см. разделы «Требования» и «Быстрый старт» ниже.
- **Предупреждение Windows SmartScreen**: установщик не имеет цифровой подписи, поэтому Windows может показать «Windows защитил ваш компьютер». Нажмите «Подробнее», затем «Выполнить в любом случае». Чтобы проверить подлинность файла, сравните его сумму SHA-256 с указанной в `SHA256SUMS.txt`, который публикуется с каждым выпуском:

```powershell
Get-FileHash .\yt-dlp-gui-setup-X.Y.Z.exe -Algorithm SHA256
```

- Ничего не отправляется автоматически: вы проверяете и редактируете отчёт, затем открываете заранее заполненную страницу обращения на GitHub (или копируете отчёт).

## Требования

- Windows
- [Python 3](https://www.python.org/) с Tkinter (входит в стандартную установку)
- `yt-dlp.exe` и, желательно, [ffmpeg](https://ffmpeg.org/): мастер установки скачивает их при первом запуске

## Быстрый старт

1. Скачайте или клонируйте этот репозиторий и перейдите в его папку.
2. Запустите `yt-dlp-gui.bat` (или `pythonw yt-dlp-gui.pyw`).
3. При первом запуске позвольте мастеру установить yt-dlp и ffmpeg; он остаётся доступен в меню параметров.
4. Вставьте URL, выберите параметры, затем скачайте, добавьте в очередь или откройте инспектор для плейлиста.

## Конфиденциальность и ответственное использование

- Это программное обеспечение не отправляет данные автору и не содержит телеметрии. Сетевые подключения выполняют yt-dlp (видеосайты), мастер установки (GitHub) и инструмент реестра (поиск на YouTube). Автоматическая проверка обновлений также обращается к GitHub при запуске (не чаще раза в сутки); её можно отключить в «Проверить обновление программы…».
- Ваши cookie остаются на вашем компьютере: yt-dlp читает их локально из выбранного браузера.
- Используйте инструмент в соответствии с авторским правом, условиями использования сайтов и законами вашей страны и скачивайте только то, что вам разрешено скачивать.

## Разработка

Тесты (переводы, реестр, формирование команд, интерфейс, мастер установки, документация) запускаются командой:

```bash
python -X utf8 -m unittest discover -s tests -t .
```

Они также автоматически выполняются на GitHub при каждой отправке. Номер версии задаётся переменной `__version__` в `yt-dlp-gui.pyw` и должен совпадать с заголовком [CHANGELOG.md](../CHANGELOG.md). Файлы переводов интерфейса находятся в `lang/`, а этой документации — в `docs/`; проверка носителями языка приветствуется.
