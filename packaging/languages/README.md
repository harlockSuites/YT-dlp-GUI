# Traductions de l'installateur

Fichiers de langue d'Inno Setup copiés ici pour les langues absentes de l'installation d'Inno Setup 6.x :

| Fichier | Langue | Origine |
|---|---|---|
| `ChineseSimplified.isl` | chinois simplifié | officiel, Inno Setup 7.1 (Zhenghan Yang) |
| `Vietnamese.isl` | vietnamien | non officiel (memecoder) |
| `SerbianLatin.isl` | serbe (latin) | non officiel (Davor Nikolić) |
| `Hindi.islu` | hindi | non officiel (Him Prasad Gautam) |

Source : [dépôt d'Inno Setup](https://github.com/jrsoftware/issrc) (`Files/Languages` et `Files/Languages/Unofficial`), distribué sous la licence d'Inno Setup. Les traductions non officielles sont de qualité variable : les corrections sont bienvenues.

Il n'existe pas de traduction filipino pour Inno Setup : l'installateur affiche à la place, sur la page d'accueil, une phrase en filipino indiquant que le logiciel est disponible en filipino.
